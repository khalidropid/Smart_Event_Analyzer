# Smart Event Analyzer

أداة Python بسيطة لتحميل الأحداث والتحقق منها وتحليلها.

## الملفات

- `main.py`: نقطة التشغيل.
- `utils.py`: تحميل بيانات الأحداث.
- `validator.py`: قواعد التحقق من صحة الحدث.
- `analyzer.py`: منطق التحليل.

## التشغيل

يتطلب Python 3 ولا توجد حزم خارجية معلنة.

```bash
python main.py
```

راجع صيغة الأحداث المتوقعة في `utils.py` قبل إضافة بيانات جديدة.
